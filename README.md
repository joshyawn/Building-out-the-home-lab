# Enterprise Home Lab

## Project Overview

This project focuses on building a virtualized home lab to develop hands-on experience in network engineering, system administration, cybersecurity, and enterprise infrastructure while preparing for the Cisco CCNA certification.

## Project Objectives

- Configure and administer a Proxmox virtualization environment.
- Deploy Linux and Windows virtual machines.
- Implement containerized services using Docker.
- Configure DNS, DHCP, VLANs, trunking, and firewall policies.
- Deploy and administer an Active Directory environment.
- Implement network monitoring and troubleshooting.
- Practice network segmentation and infrastructure security.
